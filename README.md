# Product Supplier Finder

Este projeto tem como objetivo atuar como um crawler para encontrar fornecedores de produtos na internet, similar ao MailerFind. Dado um produto, ele buscará por empresas que o fornecem e tentará extrair informações relevantes, incluindo contatos (especialmente e-mails).

## Funcionalidades (Planejadas)

- Busca na web por fornecedores de um produto específico.
- Crawling em sites de fornecedores para coletar dados.
- Extração de informações de contato (e-mails, telefones, etc.).
- Armazenamento de dados de fornecedores em um banco de dados.
- Interface para consulta de fornecedores por produto.
